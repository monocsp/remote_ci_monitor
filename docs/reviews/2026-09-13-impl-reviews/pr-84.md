## B. 버그 · 오류 경로 · 보안

**「원시 문자열을 넘기는 다른 호출자」 — 없다.** `src/` 에서 `.data_dir` 을 쓰는 곳 전부(`cli.py:747·1395·1577`, `janitor.py` 7곳, `worker.py` 6곳, `remote_workers.py` 2곳, `server.py:643·713·1403·2656`)가 `config.data_dir` **프로퍼티**(`config.py:182-183 expanduser()`)를 쓴다. `config.server.data_dir` 원시 문자열을 읽는 곳은 `config.py` 자신과 `tools/guard_production.py`(가드는 원시 값을 자기가 푼다 — 이 PR 범위 밖)뿐. 워커 설정도 `WorkerConfig.data_path`(`config.py:304`)로 푼다.

1. **P1(기존 문제 · 이 PR 이 범위를 넓힘 · 오너 결정) — `/api/status` 가 데이터 디렉터리의 절대경로를 인증 없이 내보낸다.** `hostsample.py:86-101 _disk_usage()` 가 `"path": str(path)` 를 표본에 넣고 그대로 `pools[].hosts[].disk.path` 로 나간다. 검증 보고 V1.1 의 실측이 그것이다: `disk == {…, "path": "/Users/fmmentalcare/.local/share/rcm-verify-web"}` — 사용자 이름이 든 홈 경로. `read_auth` 기본은 `"none"`(`config.py:91`)이고 운영 서버는 `0.0.0.0:8787` + mDNS 광고라 같은 LAN 의 누구나 읽는다. 이는 (a) 집안 규칙 「상태·오류·로그에 경로·비밀 금지」와 (b) 이 명세 자신의 I4 「서버는 보안상 `data_dir` 을 API 로 안 내리므로」와 정면으로 어긋난다. B5 이전에는 `examples/server.toml` 의 기본값(`~/.local/share/rcm`)대로 설치한 서버가 **버그 덕에** 경로를 안 내보냈고, #84 가 그 서버들에서도 경로를 내보내기 시작했다(절대경로 설정은 M4 부터 이미 내보냈다). 소비자는 없다: `app.js:1718` 주석 「경로는 그리지 않는다」, `render_text.py`·`cli.py` 에 `disk.path` 를 읽는 곳 없음(grep). 원격 워커의 heartbeat 표본도 같은 키를 실어 보낸다. 제안: `_disk_usage()` 에서 `path` 를 빼고(로그의 기동 줄 `data <경로>` 만 남긴다) `test_hostsample_disk_path.py:75` 의 `sample.disk["path"] == sampler.disk_path` 단언을 `sampler.disk_path` 검사로 바꾼다 — 또는 의도라면 I4 문장과 집안 규칙을 고친다. 재현: `curl -s http://<서버>:8787/api/status | jq '.pools[0].hosts[0].disk.path'`.
2. **P2 — 새 테스트가 그 경로 노출을 잠근다.** `tests/test_hostsample_disk_path.py:75` `assert sample.disk["path"] == sampler.disk_path` — 1번을 고치면 이 줄부터 빨개진다. 표본에 `disk` 가 있는지는 `total_bytes > 0` 으로 충분하다.
3. **문제 없음 — 테스트가 포트를 열지 않는다.** `App.start()` 는 청소기·샘플러·(꺼진) mDNS 만 띄우고 HTTP 소켓은 `serve()`(`server.py:2654`) 가 만든다. `advertise = false` 라 mDNS 도 없다. 이 Mac 의 8787 운영 서버와 충돌하지 않는다.
4. **문제 없음 — HOME 을 tmp_path 로 바꿔 실제 홈을 안 건드린다.** `data_dir = "~/rcm-devtest"` 가 `tmp_path/rcm-devtest` 로 풀리는 것까지 단언.
5. **문제 없음 — 부분 실패 설계 유지.** 경로가 없어도 `_disk_usage` 는 `None` 을 돌려주고 표본의 다른 칸은 산다(변경 없음).
