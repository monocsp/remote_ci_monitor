## 비고 (오류는 아니지만 다음 사람이 알아야 할 것)

1. **basic 서버에서 `/api/health` 는 토큰 없이 200 이고 wheel 만 401** — M5i 보고 비고 1 그대로. 래퍼는 이제 그 401 을 `answered 401: read access requires a token on this server` + exit 3 으로 말한다(옛 래퍼는 curl 의 22).
2. **0.2.4 실물 클라는 health 503 에서 `FAIL server janitor stale`(버전 없음)** 로 답한다 — `client` 행·경고는 새 클라 코드의 것이므로 옛 릴리스로는 ③ 을 볼 수 없다. 그래서 ③ 은 0.2.6 wheel 에 `__version__` 만 바꾼 venv 로 봤다(M5i V4.6 과 같은 방법).
3. **인라인 블록의 `mktemp -d` 는 macOS 에서 `TMPDIR` 을 안 쓴다**(템플릿이 없으면 `/var/folders/…/T`). 스크립트는 `mktemp -d "${TMPDIR:-/tmp}/rcm-client.XXXXXX"` 라 `TMPDIR` 을 따른다. 둘 다 `trap … EXIT` 로 지우므로 문서 결함은 아니다.
4. **`capture.py all` 은 16장을 다 다시 만든다** — 픽셀 차이가 나므로 이 PR 에는 `cli-check.png` 만 넣고 나머지는 되돌렸다. 다른 화면의 재생성은 그 화면을 바꾼 PR 의 몫.
