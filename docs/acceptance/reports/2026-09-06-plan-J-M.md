## FAIL 요약 (심각도 순: 보안 > fail-open > 기능 > 문서/문구)

**J·K·L·M 절에 하드 FAIL 없음.** 전 항목 PASS. 아래는 발견한 경미한 불일치(사양 위반 아님)와 부수 발견:

- (기능·경미 — **I 절 소관**, J2/`--by` 검증 중 발견) 클라이언트 `client.toml` 의 `label` 키와 `RCM_LABEL` 환경변수가 `rcm run` 에 **무시**된다. `cli.py:199 cmd_run` 이 `label = args.by or default_label(None)` 로만 정하고 `cfg.label`(config.py 가 로드함)을 쓰지 않는다. 게다가 기본 라벨은 `default_label(None)` → `$USER@<host>` 라서 PLAN 클라이언트 설정 주석의 「비면 `<토큰 이름>@<호스트명>`」과도 다르다(토큰 이름이 아니라 OS 사용자). 재현: `client.toml` 에 `label = "cfg-label@x"` → `rcm run ok --client-config …` → requester.label = `fmmentalcare@epeuem-ui-Macmini`. 책임: `cli.py cmd_run`/`_client` 라벨 배선 + `config.py` label. (I5/I4 소관 — A~I 담당에게 이관.)
- (문서/문구·경미) `rcm top` recent 가 취소/kill 잡의 종료코드를 원 프로세스 값 `exit -15`/`exit -9` 로 표시. 웹(목업14)은 의미 종료코드 `cancelled · exit 2`. 터미널/웹 표기 불일치. 책임: `core/render_text.render`(recent 줄) vs `web/app.js recentLine`.
- (문서/문구·경미) 모바일(목업21)은 `.card` 마크업을 명시하나 구현은 리플로된 `<table>` 로 같은 시각 결과(한 열·무-가로스크롤)를 낸다. 책임: `web/app.js`(모바일 큐 렌더)·`style.css`.
