## 오류와 수정

둘 다 PR #109 브랜치에 커밋 `4319220` (`fix: tool_missing 잡은 대장 창에서 빼고 원격 finish 의 도구는 이름만`).
검사: `ruff check` · `ruff format --check` · 전체 `pytest` **3449 passed, 3 skipped** · `node --test tests/web` 443 pass ·
`scripts/mutcheck.py` 27/27.

1. **G4.4 — `tool_missing` 잡이 실패 대장 창에 세어졌다.** `Store.failure_stats` 는 `succeeded/failed/timed_out`
   을 다 창에 넣었고 `tool_missing` 도 `failed` 다. 그러면 결정적 실패 셋이 「4 중 3」으로 보인다. 수정:
   `store.WINDOW_EXCLUDED_CODES = ("tool_missing",)` 를 창 질의에서 빼 취소·유실처럼 다룬다(결정 68 의 분모는
   스크립트가 **돈** 잡). 테스트 `tests/test_requires.py::test_a_tool_missing_job_is_left_out_of_the_failure_window`
   (앵커가 `tool_missing` 잡 자신이어도 창은 이름 실패만 센다). 문서: configuration.md 의 창 설명 · CHANGELOG.
2. **G4.15 — 원격 finish 의 `summary_args.tool` 이 경로를 그대로 저장했다.** 검증 시나리오 ①의 `path` 키는
   버려졌지만 `tool` 값이 절대경로면(`/opt/secret/bin/fvm`) 그대로 `GET /jobs/<id>`·`/api/status.recent` 에
   실렸다 — 로컬 워커는 `RequiredToolMissing.public_name` 으로 basename 만 남기는데 원격은 서버가 워커를
   믿었다. 수정: `remote_workers._preflight_summary` 가 basename 만 남기고 빈 이름(`/opt/bin/`)은 400. 테스트
   `test_finish_reduces_a_tool_given_as_a_path_to_its_name` · `test_finish_rejects_unknown_or_inconsistent_structured_summaries[body5]`.
3. **G4.10 — 문서.** `local preset tools` 행은 FAIL(exit 1)이다. 명세는 「FAIL 이면 문서가 그렇게 말한다」 —
   configuration.md 에 넣고 `tests/test_docs_m5j_requires.py::test_configuration_says_the_local_row_fails_and_the_window_skips_tool_missing`
   로 잠갔다.

## 오너 결정

- **G4.5 비고 — 선언한 절대경로가 잡 로그에 그대로 찍힌다.** `requires = ["/usr/bin/true"]` 면 잡 로그(토큰
  보호)에 `[rcm] required tools: /usr/bin/true ok`, `rcm check` 의 `local preset tools` 행에도 `needs-abs
  (/usr/bin/true ok)`. 공개 상태(`summary_args` · `/api/status`)는 basename 만이고 서버 PATH·찾아낸 경로는
  어디에도 없다. 구현과 문서(「the log names the missing entry as you declared it」)와 기존 테스트
  (`test_a_missing_absolute_path_reports_only_the_tool_name`)가 이것을 설계로 잠갔고, 명세 §2 G4 가 금하는 것은
  「PATH 와 도구 경로(찾아낸)」다. 시나리오 G4.5 의 「경로 없음」을 선언 문자열까지로 읽는다면 로그도 basename
  으로 바꿔야 한다 — 그러면 같은 이름을 두 경로로 선언한 프리셋에서 어느 것이 빠졌는지 로그로 알 수 없다.
  **지금은 설계대로 둔다**(통과). 바꾸려면 오너 결정.
